Sales Performance Dashboard (Excel)

This repository contains a sales analysis project built in Microsoft Excel, supported by a detailed report. The project explores sales transaction data to uncover insights into revenue trends, customer purchasing behavior, product category performance, and payment preferences.

Project Overview

The dashboard presents key sales metrics in an interactive format, allowing users to easily explore trends, compare performance across categories, and analyze changes over time. It is designed to support informed decision-making related to sales strategy, pricing, and promotions.

Key Focus Areas
	1.	Overall revenue and order performance
	2.	Product category performance and contribution
	3.	Identification of top- and low-performing categories
	4.	Customer payment method preferences
	5.	Monthly sales trends and seasonality
	6.	Effect of discounts on revenue

Tools Used
	1.	Microsoft Excel
	2.	Pivot Tables
	3.	Slicers
	4.	Timeline
